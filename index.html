OWASP TOP 10 (A03:2021) // DEFENSIVE CASE STUDY

Cybersecurity Case Study: SQL Injection (Defensive)

Comprehensive breakdown of injection mechanics, vulnerability vectors, and parameterized defense.

Defensive Engineering
defensive_security_audit.sql
// VULNERABLE: Direct concatenation allows query tampering
String query = "SELECT * FROM users WHERE username = '" + userInput + "' AND pass = '" + pass + "'";
// SECURE: Parameterized query (Prepared Statements) treats input strictly as data
PreparedStatement stmt = conn.prepareStatement("SELECT * FROM users WHERE username = ? AND pass = ?");
stmt.setString(1, userInput);
stmt.setString(2, pass);

What is the vulnerability?

SQL Injection happens when an application puts untrusted user input directly into a database query string, causing the input to be parsed and executed as SQL instructions instead of literal data.

How can it happen?

It occurs when database queries are constructed by joining raw strings from forms, URL query parameters, or HTTP headers without strict server-side validation, type checking, or parameter binding.

What are the risks?

Catastrophic data exfiltration, database corruption or loss, administrative authentication bypass, compliance penalties (e.g. GDPR/DPA), and irreparable damage to organization reputation.

How can developers prevent it?

Enforce parameterized queries (Prepared Statements), employ Object-Relational Mappers (ORMs), apply strict server-side input allowlisting, and sanitize all data outputs.

Security practices to implement

  • Least-Privilege Database Accounts: Restrict database users so web applications cannot execute DROP or administrative schema mutations.
  • Cryptographic Hashing: Protect authentication credentials with salt and Argon2/Bcrypt; return generic authentication error messages.
  • Strict Server-Side Validation: Never trust client-side validation alone; sanitize and cast all incoming payloads.
  • Automated Audits & Dependency Management: Conduct regular static code analysis (SAST) and patch vulnerabilities promptly.
